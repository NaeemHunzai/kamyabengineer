Help — How to use

Follow the wizard: Solar sizing → Appliances → Financial. All currency values auto-convert based on selected country; you can edit the local tariff if needed.

  • PSH: Peak Sun Hours — affects generation estimate.
  • System losses: Default 20% to account for inverter/wiring/soiling.
  • Battery hours: Hours of backup required (for hybrid/off-grid).
  • Appliances: Add items to build accurate daily kWh.
