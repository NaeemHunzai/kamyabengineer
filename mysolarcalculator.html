Help — How to use

Use the wizard: fill Inputs → add Appliances (optional) → Calculate. All results show in step 3.

  • Daily consumption can be entered directly or derived from monthly bill and tariff.
  • Add appliances for a detailed load — the calculator will use this when daily is empty.
  • Charts and exports appear after calculation.
